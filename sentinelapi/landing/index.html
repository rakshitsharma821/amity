HIGH SEVERITY GET /orders/{id}

Broken Object Level Authorization (BOLA) in /orders/{id}

User A ('alice') successfully retrieved User B's ('bob') private order (ID: 3) without authorization. In a zero-trust model, users must only query records tied directly to their authenticated session token.

curl -X GET "http://localhost:4000/orders/3" \ -H "Authorization: Bearer eyJhbGci...[redacted]" \ -H "Accept: application/json"
🛡️ Concrete Fix: Enforce strict ownership validation at the data-access layer for /orders/{id}. Verify that the requesting subject's ID (extracted securely from the authenticated token) matches the resource's owner_id before executing the database query.
